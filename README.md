# code-rewiew-lab-2

Lab 2:

Глобальное использование using namespace std - во всех файлах присутствует директива, загрязняющая глобальное пространство имён. Требуется замена на явный префикс «std::».
Отсутствие префиксов у классов - классы и структуры не имеют обязательных префиксов «F», «U», «A» и т.д. (например, «Node», «Stack», «Queue», «LinkedList», «Spisok»). Необходимо добавить соответствующие префиксы.
Некорректный стиль именования - имена переменных, функций и методов не соответствуют PascalCase:
Имена в стиле camelCase или с подчеркиваниями
Использование транслита (например, «Dannye», «Predydushiy», «Perviy», «Uzel»)
Слишком короткие имена («n», «m», «x», «i», «V», «D», «L»)
Некорректное расположение скобок - открывающие фигурные скобки «{» расположены на той же строке, что не соответствует стилю Allman. Требуется перенос на новую строку.
Отсутствие пробелов вокруг операторов - в выражениях вида «i<n;i++» отсутствуют пробелы, что снижает читаемость.
Отсутствие деструкторов - во многих классах с динамической памятью нет деструкторов, что приводит к утечкам памяти.
Отсутствие обработки исключений - нет блоков try-catch для обработки ошибочных ситуаций.
Отсутствие проверок корректности ввода - ввод данных с клавиатуры не проверяется на корректность (например, ввод букв вместо чисел).
Отсутствие проверок открытия файлов - операции с файлами не проверяют успешность открытия.
Имена функций не отражают суть операций - некоторые функции названы неинформативно (например, «EvenHead», «MiddleElement», «IsNumber»).
Несколько переменных в одной строке - объявления вида «int n1, n2, n3;» снижают читаемость.
Отсутствие константности методов - методы, не изменяющие объект, не помечены как «const».
Отсутствие модульности - весь код находится в одном файле, нет разделения на заголовочные файлы и файлы реализации.
